Scripting

You can create pretty complex puzzles with the built in SDK functions, but if you need more complex logic you can write your own C# scripts.

Where your scripts go

Your scripts must be in the Assets/PuzzleScripts folder. The SDK creates it for you when you import it (or click Tools > Big Puzzle SDK > Setup > Set up scripts folder).

  • The folder has an assembly definition, so everything inside this folder is compiled into your mod DLL. A script anywhere else in the project is not part of that DLL and will not run in game
  • The DLL's name comes from the assembly definition inside the folder. You can rename it, just make sure it doesn't clash with another puzzle's DLL name.
  • Changes to scripts need a game restart to show up. Ctrl+F2 reloads scenes and assets, not code.

A first script

using System.Collections.Generic;
using BigPuzzleSDK;
using UnityEngine;

public class AllBoardsCorrect : MonoBehaviour {
    [SerializeField] private List<PuzzlePegBoard> boards;

    // Wire each Peg Board's On Correct to this.
    public void BoardCorrect() {

        // Only run this logic if you are host.
        if (!PuzzleSDK.IsHost) return;

        foreach (PuzzlePegBoard board in boards) {
            if (!board.IsCorrect) return;
        }
        OnSuccess();
    }

    private void OnSuccess() {
        // Do something here, like opening a door or calling PuzzleSDK.Win().
    }
}
  • Save it as AllBoardsCorrect.cs in Assets/PuzzleScripts (the file name must match the class name). Put the script on an object in your puzzle and drag your Peg Boards into the Boards list in the Inspector, like any Unity script.
  • On each Peg Board, click + under On Correct, drag in the object that has the script, and pick AllBoardsCorrect > BoardCorrect.
  • Every time a board changes to correct, BoardCorrect() runs and checks all the boards. Only when all of them are correct does it reach OnSuccess().
  • BoardCorrect() runs for everyone because UnityEvents from the board run for everyone. That's why we return if !PuzzleSDK.IsHost
  • Write Debug.Log, Debug.LogWarning and Debug.LogError as usual. In game they appear in the BepInEx console and log file, starting with [Creator]. When you export, the SDK points these calls (and print) at its own logger in the copy of your DLL, because the game's Unity doesn't have them. Your scripts in the project stay as you wrote them.

The PuzzleSDK class

Member What it does
PuzzleSDK.IsHost Static. True on the host, and in single player.
PuzzleSDK.players Static. Read-only list of every player (see Players).
Win() Host only. Fires every Confetti and releases every Gourd Vice, then On Win.
IsWon Read-only. The puzzle has been won.
IsRunning Read-only. A Start Switch is on.

Players

PuzzleSDK.players lists every player in the lobby. The host is always first, then players in the order they joined, and the list is in the same order on every PC. A player who disconnects stays in their place with isOnline false, and gets the same entry back if they rejoin. To remember something about a player, keep a Dictionary<string, T> on the host, keyed by id.

Member What it does
id, name The player's platform id (their Steam id, for example), which stays the same when they rejoin, and their name.
isHost, isLocal, isOnline Whether they are the host, whether they are the player on this PC, and whether they are in the game right now.
colorHead, colorBody, colorFeet The colors they picked.
position, headRotation Where they are in the world, and which way their head is turned. An offline player keeps the last values.
seat The PuzzleSeat from your puzzle they are sitting in, or null.
hat, held The name of what they wear on their head (the blindfold slot) and of what they hold in their hands, or null. For your own Items this is the name of the object, for a Vanilla Item its type.
Teleport(Transform), Teleport(Vector3, Quaternion?) Host only. Stands the player up if they sit, then moves them. Without a rotation they keep the way they face.
EjectFromSeat() Host only. Stands the player up if they are sitting, where the game puts them when they stand.
DropItem(), DropHat() Host only. Makes the player put down what they hold, or take off what they wear on their head.

Use these for the puzzle's own needs, like resetting a step or sending someone back to the start. Players notice being moved or having things taken from them, so don't use them for anything else.

Synced variables

Type Holds Range
SyncedInt A whole number any whole number
SyncedBool True or false
SyncedString Text up to 16 KB
SyncedDict Text keys and text values up to 16 KB in total
SyncedEvent Nothing: a call that every player runs argument: any whole number

How they work, in the same four rules as everything else:

  • Only the host changes them. Set and Add are ignored on other PCs, so you can call them from code that runs everywhere.
  • Everyone reads Value.
  • Changed runs on every PC when the value changes, the host's too.
  • Changed also runs for a player who joins later and finds a value different from the starting one.

SyncedInt

using BigPuzzleSDK;
using UnityEngine;

public class Score : MonoBehaviour {
    // Make synced variables as fields, like this
    private readonly SyncedInt score = new SyncedInt("score");

    void Awake() {
        score.Changed += value => Debug.Log("score is now " + value);
    }

    void Update() {
        // Calls on other PCs are ignored, so this is safe to run everywhere
        if (Input.GetKeyDown(KeyCode.Alpha1)) score.Add(1);
        if (Input.GetKeyDown(KeyCode.Alpha2)) score.Add(-1);
    }
}

new SyncedInt(name, initialValue = 0)

Member What it does
Value The current value. Read-only.
Changed event Action<int>: runs on every PC with the new value.
Set(int) Host only. Any whole number.
Add(int) Host only. A negative number takes away.

SyncedBool

private readonly SyncedBool open = new SyncedBool("open");

void Awake() {
    open.Changed += isOpen => door.SetActive(!isOpen);
}

new SyncedBool(name, initialValue = false)

Member What it does
Value The current value. Read-only.
Changed event Action<bool>: runs on every PC with the new value.
Set(bool) Host only.

SyncedString

private readonly SyncedString title = new SyncedString("title");

void Awake() {
    title.Changed += text => label.text = text;
}

new SyncedString(name, initialValue = "")

The host keeps the text and sends it to everyone, including players who join later, so there is no size to choose. It can be up to 16 KB; longer text is cut off, with a warning in the log. Like the other synced variables, make it where you declare it (not later), so every PC makes them in the same order.

Member What it does
Value The current text. Read-only.
Changed event Action<string>: runs on every PC with the new text.
Set(string) Host only.

SyncedDict

private readonly SyncedDict names = new SyncedDict("names");

void Awake() {
    names.Changed += key => Debug.Log(key + " is now " + names.Get(key, "(removed)"));
}

void OnPlayerPressed(PuzzlePlayer player) {
    names.Set(player.id, player.name);
}

new SyncedDict(name)

Text keys with text values. The host keeps it and sends it to everyone, including players who join later. Everything together can take up to 16 KB. To keep a number, store it as text (count.ToString() and int.Parse).

Member What it does
Count, Keys How many entries there are, and a list of their keys. Read-only.
ContainsKey(key), TryGetValue(key, out value), Get(key, fallback = "") Look an entry up. Read-only.
Changed event Action<string>: runs on every PC with the key that was added, changed or removed.
Set(key, value) Host only. Returns false if it was not stored: the key is empty, or there is no room left.
Remove(key), Clear() Host only.

SyncedEvent

A synced event is a function call that every player runs. It doesn't hold a value.

new SyncedEvent(name)

Member What it does
Fire(int argument = 0) Runs Fired on every PC is called from host. Runs FiredFromClient on host if called from client.
Fired event Action<T>: runs on every PC with the argument.
FiredFromClient event Action<PuzzlePlayer, T>: runs on the host only, with the player who fired it and the argument.

Other types

An event can carry a bool, float, string, Vector3, Vector2, Quaternion or PuzzlePlayer. string can be up to 16 KB.

private readonly SyncedEvent<string> say = new SyncedEvent<string>("say");

void Awake() {
    // Runs for everyone including host when host calls Fire
    say.Fired += text => {
        label.text = text;
    };

    // Runs on host when client calls Fire.
    say.FiredFromClient += (player, text) => {
        // in this example the host sends the event to everyone with the player's name appended.
        say.Fire(player.name + ": " + text);
    };
}

public void SomeFunction() {
    say.Fire("cool text");
}
