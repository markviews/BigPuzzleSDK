# Big Puzzle SDK

An SDK to build custom puzzles for **Big Walk**.
<br>Can also be used to create custom items, chairs or other non puzzle things too.
<br>I love Big Walk and hope the community makes some awesome puzzles using this SDK!

Playing: Use [r2modman](https://thunderstore.io/c/big-walk/p/ebkr/r2modman/) to install puzzles you want
<br>Creating: See [Getting Started](https://markviews.github.io/BigPuzzleSDK/getting-started.html)

![Building a peg board puzzle in Unity, then solving it in game](https://raw.githubusercontent.com/markviews/BigPuzzleSDK/main/docs/images/puzzle-demo.gif)

Please [create an issue](https://github.com/markviews/BigPuzzleSDK/issues/new) if you have a bug report.
<br>Please [create a discussion post](https://github.com/markviews/BigPuzzleSDK/discussions) for feature requests, sharing your work, looking for feedback or anything else.

The SDK contains no Big Walk assets. It reads the game's models from your own copy of the game. The game's assets belong to House House.
